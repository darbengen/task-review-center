# 任务中心 MCP

[下载最新版安装包](https://github.com/darbengen/task-review-center/releases/latest) · [更新记录](CHANGELOG.md) · [MIT 开源许可](LICENSE)

把 Codex 的任务整理为「运行中 / 待审查 / 已完成」三栏，通过右上角按钮切换到独立的 ChatGPT 聊天任务界面。支持确认、撤销、星号置顶、备注、搜索及 Work 任务归档。

这是 darben 的自建插件，并非 OpenAI 官方产品。分享包不包含作者的任务、聊天、备注、登录信息或密钥。无需另填 API Key，也不调用付费模型接口。

## v0.2.0 的变化

- 运行中任务独立显示，结束或中断后进入待审查；待审查不会因为放久了自动变成已完成。
- 待审查默认显示最近 7 天有真实对话的任务；已完成默认显示最近 7 天确认的任务。两栏均可独立「显示全部」。
- 星号表示栏内置顶，同组按最近真实对话倒序；后台刷新和确认动作不会冒充新对话改变顺序。
- Chat 聊天独立界面与 Work 三栏切换；搜索、草稿和滚动位置分别保留。重新打开默认回到 Work 三栏。
- 修复应用重开后辅助连接失效的问题；默认连接不可用时使用本机官方 Codex 核心，恢复只读同步。
- Chat 通过官方账号接口识别当前账号，修复新版应用移除旧账号缓存字段后无法读取聊天的问题。

## 最省事的安装方法

需要 macOS、Python 3.9 或更新版本，以及支持插件和 MCP 全页入口的 Codex 桌面版。后台仅使用 Python 标准库，无需 pip 安装依赖。Windows 不支持；Linux 未验证。

1. 解压，把 `task-review-center` 文件夹放到长期保留的位置，安装后不要移动或删除。
2. 将文件夹交给 Codex，并复制下面这段话：

> 请帮我安装这个任务中心插件。先阅读文件夹里的 README.md，运行 python3 prepare.py 生成本机启动路径及运行副本。使用你可用的 plugin-creator 技能，把此插件注册到本机 personal marketplace；保留现有插件和配置，遇到同名插件先检查来源，不覆盖。然后用 codex plugin add task-review-center@实际市场名 安装。不要复制别人的任务数据，不要修改官方数据库，不要重启正在执行任务的应用。安装后验证 MCP 初始化、工具列表与页面资源读取，并告诉我在哪里打开任务中心。

## 手动准备和接入

在解压后的 `task-review-center` 目录打开终端：

```sh
python3 prepare.py
```

这个命令只改当前文件夹的 `.mcp.json` 和 `runtime/`，不会改 Codex 的配置或已有任务。生成的 `.mcp.json` 使用当前电脑的 Python 和插件路径。

要在 Codex 中出现插件入口，还需登记 personal marketplace 并安装。建议交给上面的 Codex 安装提示词处理。本包不自动覆盖 marketplace 配置。普通 MCP 客户端不一定支持全页界面。

安装后打开新对话，输入「打开任务中心」，或在应用的「探索 / 更多」中寻找入口。能否固定到一级侧栏由宿主版本决定。

## 从旧版升级

先保留旧插件目录，并备份自己的 `~/Library/Application Support/CodexTaskReview/`。把新版解压到另一个长期目录，运行 `python3 prepare.py`，通过正常插件管理流程把已登记的来源更新到新目录并重新安装。不要覆盖旧版 `runtime/releases/` 中的不可变文件，也不要删除审查数据。

如果页面仍是旧布局，先关闭任务中心栏目再进入。仍显示旧连接或旧后台持续运行时，等其他任务结束后再完全退出并重开 Codex；仅关闭窗口可能不足以更新连接。升级验证不需要归档或确认真实用户任务。

本版沿用原审查数据目录；如果使用过本地试验版的「30 天自动完成」，会将这类自动归类恢复为待审查，保留手动确认、备注和星号。

## 使用与数据

- 「确认」是本地审查标记，不表示 AI 已完成任务，也不会发消息。
- Work 归档调用官方接口，并在界面二次确认。运行中任务不能归档，Chat 界面不提供归档。
- 审查数据保存在自己的 `~/Library/Application Support/CodexTaskReview/`，不是解压目录；Chat 记录在其 `chat/` 子目录。修改前保存历史备份，采用锁、版本检查和原子写入。
- Work 目录通过官方 App Server 读取。默认辅助 socket 不可用时，插件启动并管理本机官方核心的 stdio 连接，不重启桌面应用。目录读取断线最多从第一页重连一次，归档等写入不会自动重放；权限或协议拒绝不会通过切换连接绕过。
- 为判断运行状态及最近真实对话时间，插件在本机扫描允许目录中的会话日志，仅把生命周期信息和时间戳加入目录，不保存消息正文副本，也不将日志上传到外部服务。
- Chat 只读应用目录数据库的标题、时间与项目元数据；默认通过官方 `account/read` 确认当前账号，不提取登录凭据，不写官方数据库。账号不明或切换中时隐藏旧账号列表，保留审查记录。
- Chat 原文链接打开 chatgpt.com 对话；Work 使用 Codex 会话链接。不能保证 Chat 链接在所有宿主版本中直接切换到原生聊天页。
- 连接不可用会提示并保留已有记录。插件服务运行时约 8 秒同步；服务停止后，下次启动补同步。

## 兼容性与排障

本项目在 macOS Codex 桌面环境开发，依赖宿主的 MCP 全页入口、官方核心接口及本机聊天目录格式。隔离测试通过不代表所有 Codex 版本或接收者电脑都兼容。

- 找不到 Python：安装 Python 3.9+，重新运行 `python3 prepare.py`。
- Work 无法读取：先打开 Codex 并确认已登录。非默认安装位置可通过 MCP 环境变量 `TASK_REVIEW_CODEX_BIN` 指定官方核心程序路径。
- 显式设置了 `TASK_REVIEW_CORE_SOCKET`：仅使用指定地址，不会回退到另一环境；请检查该地址是否有效。
- Chat 无法读取：先打开应用聊天列表等待目录同步；宿主不提供对应目录表或账号接口时，该功能不可用。
- 页面入口不出现：检查插件已启用并尝试新对话；普通 MCP 客户端可能只支持工具。
- 解压后移动了目录：重新运行 `prepare.py` 并更新插件登记。不要手改已发布的 runtime 文件。
- 应用升级后失败：保留审查数据，先检查接口兼容性；不要清空任务数据修复连接问题。

卸载请在插件管理中完成，本地审查记录默认保留。

## 开发验证

后端与真实子进程回归无需第三方 Python 包，均使用临时样本数据：

```sh
python3 -m unittest discover -s tests -v
python3 tests/lifecycle-checks.py
```

界面回归需要 Node.js、`playwright-core` 以及 Chrome。可在测试环境安装 `playwright-core`，或将 `PLAYWRIGHT_PATH` 指向已有模块；`TEST_BROWSER` 可指定浏览器可执行文件，默认使用 macOS Google Chrome。

```sh
node tests/workflow-browser-checks.cjs
node tests/review-window-checks.cjs
```

测试生成的截图和报告位于 `evidence/`，不进入分享包。浏览器回归使用隔离样本与模拟宿主，不代表官方桌面窗口完整验收。核心运行文件与作者已发布的本地版本同步，分享版单独维护版本号、安装准备与公开文档。
